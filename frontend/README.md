# Hotel Desk frontend

React + TypeScript + Vite. See [the project README](../README.md) for full setup and API documentation.

```powershell
npm.cmd install
npm.cmd run dev
```

Development URL: http://localhost:5173. Vite proxies `/api` to http://127.0.0.1:8000.

Copy `.env.example` to `.env` to configure the API base URL or display currency. Run `npm.cmd run build` to type-check and create `dist/`.
